
# 🎹 MIDI to QWERTY for Android (Roblox)





## ✨ Особенности

* **Plug & Play:** Подключите MIDI-клавиатуру/синтезатор через OTG-кабель и запустите плавующее окно.
* **Разовая настройка и присеты:** Настройка расположений клавишь(единоразово), так же возможность менять пресеты для разных плейсов.
* **Маппинг нот:** Автоматическая конвертация MIDI-нот в точки нажатий нот в Roblox.
* **Фоновый режим:** Работает поверх окна Roblox через Overlay (не требует Root).

---

## Как использовать

1. **Подключите** MIDI-клавиатуру к Android-устройству через OTG.
2. **Запустите** приложение и предоставьте разрешение на отображение поверх других окон и уведомления.
3. **Нажмите** показать плавующее окно.
4. **Откройте Roblox**, зайдите в нужный плейс (например, Piano Keyboard), нажмите на клавишу на пианино/клавиатуры-midi, за тем на место где находиться виртуальная нота
